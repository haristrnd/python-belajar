## Daftar Program

### 1. Genap atau Ganjil (main.py)
- Deskripsi: program sederhana untuk mengetahui angka genap dan ganjil
- Cara menjalankan: `python main.py`
- Contoh input/output: 

    ```
    Masukkan sebuah angka: 84
    hasil: 84 adalah Genap
    Masukkan sebuah angka: 85
    hasil: 85 adalah Ganjil 
    ```


### 2. Grade Nilai (nilai.py)
- Deskripsi: sebuah program sederhana untuk menetapkan grade mulai dari Grade: A sampai  grade: D
- Cara menjalankan: `python nilai.py`
- Contoh input/output:

   ``` 
   Masukkan nilai: 85
   Grade: A
   Masukkan nilai: 70
   Grade: B
   Masukkan nilai: 55
   Grade: C 
   Masukkan nilai: 24
   Grade: D
   ```
